# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]
### Added
- Initialized React + TypeScript + Next.js application scaffold.
- Applied OWASP security best practices (secure HTTP headers, environment variable usage, input validation guidance).
- Added ESLint and Prettier configuration for code quality.
- Included sample middleware for security headers.
- Updated `.gitignore` for Node.js, environment files, and build artifacts.
- Added initial folder structure: `src/pages`, `src/components`, `src/styles`, `src/utils`, `src/types`.
- Installed and configured essential dependencies (`helmet`, `validator`, `dotenv`).
- Documented setup and security steps in project documentation.

## [0.1.0] - 2025-08-29
### Added
- Initial release of the solution base template.
- Standardized project structure: `src/`, `tests/`, `docs/`, `scripts/`, `package-feed/`.
- Dev container configuration for VS Code.
- Sample CI/CD workflow files for GitHub Actions and Azure Pipelines.
- Comprehensive `.gitignore` and `.editorconfig`.
- Documentation and changelog templates.


## Types of changes
- *Added*:  for new features.
- *Changed*: for changes in existing functionality.
- *Deprecated*: for soon-to-be removed features.
- *Removed*: for now removed features.
- *Fixed*: for any bug fixes.
- *Security*: in case of vulnerabilities.
